# User Guide

## Free-text symptom entry

On the Assessment page, choose **Describe your symptoms**, enter a description,
and click **Understand my symptoms**. Review and edit every detected symptom
using Yes / No / Not sure; adjust severity and duration if needed. Click
**Assess** only after confirming the list. Safety checks, including red flags,
run on the confirmed symptom entries.

Matching is deterministic and rule-based. It uses known symptom names and
synonyms with conservative fuzzy matching. It can miss unusual wording, local
phrases, or misspellings, and may not recognize the intended meaning. Review
each item; unrecognized phrases do not affect scoring. This feature is not a
diagnostic tool.
