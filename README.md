
# ClinixAI 🩺

### Intelligent Clinical Decision Support System

ClinixAI is an educational Artificial Intelligence project that combines Knowledge-Based Systems (KBS), Expert Systems, and Machine Learning to support clinical decision-making.

## Core Components

- Knowledge Base
- Rule-Based Expert System
- Inference Engine
- Explanation Engine
- Machine Learning Classification
- Mathematical and Probability Models
- Interactive Streamlit Dashboard

## Technology Stack

- Python
- NumPy
- Pandas
- Scikit-learn
- SciPy
- SymPy
- Streamlit
- Matplotlib
- Seaborn
- SQLite

## Installation

Clone the repository:

```bash
git clone https://github.com/Denis-7242/ClinixAI.git
cd ClinixAI
```

Create a virtual environment:

```bash
python3 -m venv venv
source venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
